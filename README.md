# 🔢✨ NumPy Analyzer 🚀

> 🌟 **Explore Arrays • Perform Calculations • Analyze Data • Learn NumPy!** 📊🐍

Welcome to **NumPy Analyzer**! 🎉💻

**NumPy Analyzer** is a beginner-friendly and interactive Python project created to explore the powerful features of the **NumPy library**. 🔢✨

This project provides a simple menu-driven interface where users can create different types of arrays, perform mathematical operations, combine arrays, search and sort data, filter values, and calculate important statistical information. 📊🚀

It is designed especially for students and beginners who want to understand **NumPy and Data Analysis concepts through practical implementation**. 🧠💡

---

# 🌈🚀 Project Overview

NumPy is one of the most important Python libraries used in **Data Science, Machine Learning, Artificial Intelligence, Scientific Computing, and Data Analysis**. 🤖📊

This project demonstrates several useful NumPy operations in one application.

Instead of performing each operation separately, **NumPy Analyzer brings multiple array operations together in a single interactive program**. 🎯💻

---

# ⭐🎯 Key Features

✨ **Multiple Array Creation**
🔢 Create 1D, 2D, and 3D arrays.

🧮 **Mathematical Operations**
Perform addition, subtraction, multiplication, and division.

✂️ **Indexing & Slicing**
Access specific elements and portions of arrays.

🔗 **Array Combining**
Combine arrays using NumPy operations.

🔍 **Searching**
Search for values inside arrays.

🔄 **Sorting**
Sort array elements for better organization.

🎯 **Filtering**
Work with selected values from arrays.

📊 **Statistical Analysis**
Calculate sum, mean, median, standard deviation, and variance.

🖥️ **Interactive Menu**
Choose different operations using a simple menu system.

# 🧭📋 Main Menu

The application provides the following main options:

### 1️⃣ 🏗️ Create a NumPy Array

Users can create different types of arrays:

🔹 **1D Array**
🔹 **2D Array**
🔹 **3D Array**

This option helps users understand how NumPy stores and organizes data in different dimensions. 🔢📦

---

### 2️⃣ 🧮 Mathematical Operations

This section allows mathematical operations between arrays.

➕ **Addition**
➖ **Subtraction**
✖️ **Multiplication**
➗ **Division**

The project works with arrays of the same size and demonstrates how NumPy can perform calculations efficiently. ⚡📊

---

### 3️⃣ 🔗 Combine or Split Arrays

This option allows users to work with arrays together.

🧩 **Combine Arrays**
✂️ **Split Arrays**

Combining arrays is useful when working with multiple sets of data and organizing them into a single structure. 📦🔢

---

### 4️⃣ 🔍 Search, Sort & Filter Arrays

This section focuses on working with array data.

🔎 **Search a Value**
🔄 **Sort the Array**
🎯 **Filter Values**

These operations help users understand how data can be searched, arranged, and selected for further analysis. 📊✨

---

### 5️⃣ 📈 Aggregates & Statistics

The project also provides useful statistical calculations:

➕ **Sum** – Finds the total of the array values.

📊 **Mean** – Calculates the average value.

📌 **Median** – Finds the middle value of the data.

📉 **Standard Deviation** – Helps understand the spread of data.

📈 **Variance** – Measures the variation in the values.

These concepts are very useful in **Data Science and Data Analysis**. 🤖📊

The final option allows users to safely exit the application.
